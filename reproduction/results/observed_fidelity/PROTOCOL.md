# Observed fidelity before completion or speed

This follow-up to #124 responds to the visible smoothing in PR126. Preserve all previous fields, selectors, and timings. No synthetic noise is added. Inputs are actual Stanford range scans with inferred normals and registration error, not noiseless samples from the reference mesh. Do not interpret a working regularizer as measured sensor noise.

Use validation views only to choose a model. The primary requirement is fidelity to the observed scan, rather than an average with the missing side. Measure zero-crossing displacement at 512 deterministic input positions that are not scalar contacts, along their input normals, with 65 offsets over [-.03,.03]. Missing crossings receive .03 and are reported separately. Also measure gradient/input-normal angle using centered finite differences at those positions. These are input-fit diagnostics, not held-out acquisition accuracy; positions may supply normal observations. The reference mesh remains a separate same-acquisition comparison, never a source of conditioning data.

Normalize errors by the median nearest-neighbor spacing of the complete input group (validation .003303, primary side .003817, object height 2). Require median crossing displacement <= one spacing, p95 <= two spacings, missing fraction <=1%, median normal angle <=15 degrees and p95 <=40 degrees. Report all failures. These explicit engineering gates reflect sample resolution; they are not a claim of exact sensor precision. Preserve observed/unobserved reference-probe and occupancy scores separately; better completion cannot compensate for failing observed fidelity.

First screen at 16,384 normals using full float64 Cholesky: length scales {.015,.03,.06,.12}, normal standard deviations {.02,.05}, contact counts {512,2048}, scalar noise variance/prior variance {1e-6,1e-4}. Amplitude stays 1/3; scalar targets stay zero. These are small declared regularizers, not injected noise. Nested farthest-point contacts come from the full scan. Explicitly report scalar variance = ratio * ell^2/3, so shortening ell does not inadvertently weaken the contact constraints. Evaluate the PR126 setting (.48,.5,512,scalar variance .0001) as a frozen control.

Among configurations passing every input-fit gate, rank by p95 displacement, then median normal angle. Promote the first three in that order, as needed, to 70,652 validation normals and require the same gates. Freeze the first passing model before any new primary test-side fields. If none qualifies, report failure instead of loosening gates. Additional experiments require a separately recorded amendment, not silently changing this search. Reference and missing-region scores are diagnostics, not selection tie breakers.

For a qualifying model, evaluate primary test-side fit, reference distances and occupancy, and create matched old/new geometry with a finer display and a resolution check. Report lost unseen-side completion honestly. Independent full-kernel conditioning remains the correctness control. No H2 speed claim transfers from the old model: new timing requires fresh matched-accuracy benchmarks, including every contact and preparation cost. Prioritize establishing a credible mean before further timing work.
